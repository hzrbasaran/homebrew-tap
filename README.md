# hzrbasaran/tap

Homebrew formulae for [rustClean](https://github.com/hzrbasaran/rustClean),
a terminal disk usage analyzer and cleaner.

```sh
brew install hzrbasaran/tap/rustclean
```

Or tap once, then use the short name:

```sh
brew tap hzrbasaran/tap
brew install rustclean
```

Prebuilt binaries for macOS (Apple Silicon and Intel) and Linux (x86_64).

The formula is updated automatically by rustClean's release workflow
(`scripts/homebrew-formula.sh`); please open issues and pull requests in
[hzrbasaran/rustClean](https://github.com/hzrbasaran/rustClean).
